# Ревью core loop Narra — проблемы, гипотезы, как чинить

Дата среза: 1–2 сентября 2026. База: `mishanaer/Narra` `main` = `62a80b7` (после PR #59). Ветка работы: `narra/core-loop-polish`.

Метод: 7 читателей кода (навигация, ридер, домен, gateway, дельта PR #51, тулинг, история) → синтез карты loop; по каждому пункту релизного чек-листа отдельный следователь с уликами `file:line`; каждую причину пытались опровергнуть три независимых проверяющих (линзы: code-path, user-symptom, regression-risk). Верификация прервана лимитом сессии — вердикты есть для C1 и C2, остальные причины помечены статусом следователя. Живые проверки: dev-client в iOS Simulator (iPhone 17 Pro Max, сборка из чистого клона) + прямые запросы к staging gateway с тестовой установкой.

> Формат по просьбе владельца: **проблема → гипотеза/причина → как чинить по пунктам**, с точной локализацией на бэке. Файлы указаны относительно корня репозитория.
